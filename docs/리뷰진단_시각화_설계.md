# 리뷰 진단 화면 설계 및 검증

2026-09-27 개정. v3 분석과 v5 인사이트를 단일 데이터 계약(`dashboard_evidence.build_evidence`)으로 읽어 대시보드를 구성한다. 화면을 탐색할 때 추가 AI 호출은 없다.

## 3초 목표

처음 보는 사람이 3초 안에 이렇게 말할 수 있어야 한다.

> 리뷰 수천 건을 AI가 주제별로 나눴더니, **팰 디자인은 지켜야 하고 최적화는 고쳐야 한다**는 게 한눈에 보인다.

화면의 주인공은 **주제별 칭찬·불만 차트 하나**다. 나머지는 이 차트를 읽게 돕거나(결론 문장), 차트에서 고른 주제를 증명한다(근거 패널).

## 화면 구성 (위에서 아래)

| 순서 | 요소 | 하는 일 |
| --- | --- | --- |
| 1 | 결론 문장 (h1) | `{지킬 것}은 지키고, {고칠 것}은 고쳐야 합니다`. 두 주제명은 차트 막대와 같은 파랑·빨강 |
| 2 | 범위 한 줄 | 게임명, 언어, 기간, AI 분석/수집 건수 |
| 3 | 주제별 칭찬과 불만 (주인공) | 나비형 막대. 0선 왼쪽 불만, 오른쪽 칭찬, 양쪽 같은 눈금 |
| 3 | 선택 주제 근거 (차트 오른쪽) | 불만:칭찬 비율 막대, 플레이 구간별 불만 비율, AI 요약, 실제 리뷰 한 줄, 원문 버튼 |
| 4 | 플레이 시간별 비추천율 | 구간별 가로 막대 + 전체 비추천율 점선. 30건 미만은 막대 없이 빗금과 건수 |

첫 화면(1280×720)에 1~3이 모두 들어온다. 390px 폭에서도 차트 전체가 첫 화면에 보인다.

## 차트 규칙

- **정렬로 결론을 만든다.** 칭찬 ≥ 불만인 주제는 칭찬순으로 위에, 불만 > 칭찬인 주제는 `불만이 칭찬보다 많은 주제` 구역 아래에 불만순으로 놓는다. 위 구역 첫 줄이 **지킬 것**, 아래 구역 첫 줄이 **고칠 것**이다.
- **강조는 두 줄만.** 지킬 것의 칭찬 막대와 고칠 것의 불만 막대만 진한 색이다. 불만 우세 구역의 다른 불만 막대는 중간 빨강, 나머지는 옅은 색이다.
- 불만 우세 주제가 하나도 없으면 불만이 가장 많은 주제를 `살펴볼 것`으로 표시하고 결론 문장도 "불만을 살펴보세요"로 낮춘다.
- 주제가 10개를 넘으면 위 구역을 줄이고 불만 구역은 최대 4줄을 항상 보인다. 가운데는 `⋯ 주제 N개 더 보기`로 접는다.
- 숫자는 막대 끝에 직접 적는다. 범례 상자, 정렬 토글, 눈금 숫자는 두지 않는다.

## 집계 기준

- 주제 막대: AI 분석 리뷰 중 해당 주제를 칭찬(P)·불만(N)으로 언급한 **고유 리뷰 수**. 한 리뷰가 여러 주제에 들어갈 수 있다.
- 선택 주제의 플레이 구간 막대: 구간별 AI 분석 리뷰 중 이 주제 불만 비율. 30건 미만 구간은 막대를 그리지 않는다.
- 플레이 시간별 비추천율: 수집 리뷰 전체의 Steam 추천 여부. AI 분류와 분모가 다르다.
- 지킬 것·고칠 것은 조사를 시작할 곳이다. 개선 효과, 인과관계, 전체 유저 대표성을 뜻하지 않는다.
- 최신순 수집은 무작위 추출이 아니므로 급상승·모집단 오차를 표시하지 않는다.
- 플레이 구간은 서로 다른 작성자 집단이며 개인의 만족도 변화가 아니다. 작성 시 플레이 시간 0은 유효값, 누락은 현재 누적 시간으로 대체하지 않는다.

## 뺀 것과 이유

| 뺀 요소 | 이유 |
| --- | --- |
| 상단 카드 3개 | 결론 문장·차트와 같은 말을 반복하고 차트를 첫 화면 밖으로 밀어냈다 |
| 주제×구간 히트맵 | 숫자(건수)와 색(비율)이 다른 것을 말해 오독을 낳았다. 선택 주제 패널의 구간 막대로 대체 |
| 감성 도넛·재미 유형·추천 속 불만 | 핵심 질문에 답하지 않는다. 분석 결과 내려받기 파일에 남아 있다 |
| 언급순·불만순 정렬 토글 | 정렬 자체가 결론을 전달하므로 하나로 고정 |

## 검증 방법

실제 `static/dashboard.html`을 브라우저로 열고 `/dashboard/data/v5` 응답만 가짜 데이터로 바꿔 1280×720, 1920×1080, 390×844에서 스크린샷으로 확인한다. 주제 선택, 접기/펼치기, 리뷰 근거 대화상자, 불만 우세 주제 없음·주제 2개·주제 0개 데이터도 확인한다.
