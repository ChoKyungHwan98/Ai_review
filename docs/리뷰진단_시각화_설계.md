# 리뷰 진단 화면 설계 및 검증

2026-09-25. v3 분석과 v5 인사이트를 단일 데이터 계약으로 읽어 대시보드를 구성한다. 화면을 탐색할 때 추가 AI 호출은 없다.

## 판단할 질문

1. 어떤 경험을 지킬 것인가: 주제별 칭찬 리뷰 수.
2. 어떤 문제를 조사할 것인가: 불만 빈도, 추천 여부와의 연관, 실제 원문.
3. 어떤 플레이 구간을 더 조사할 것인가: 작성 당시 플레이 시간별 비추천율과 불만 주제.
4. 근거가 충분한가: 수집 기간, 분석 건수, 미상 값, 작은 표본, AI 분류 한계.

## 시각화 계약

| 질문 | 표현 | 집계 기준 |
| --- | --- | --- |
| 주제별 강점과 문제 | 공통 축의 양방향 가로 막대 | 주제·감성별 고유 리뷰 수. 한 리뷰에 칭찬과 불만 공존 가능 |
| 선택한 문제의 근거 | 인접 상세 패널과 원문 대화상자 | AI 주제 분류와 실제 Steam 추천 여부를 구분 |
| 구간별 비추천 | 0–100% 공통 축 가로 막대 | 수집 원자료, 작성 시 플레이 시간. 작은 표본은 빗금과 경고로 구분 |
| 구간별 불만 | 건수 직접 표기 히트맵 | 색은 구간 내 AI 분석 대비 불만 비율. 30건 미만은 회색·점선으로 색 비교 제외 |
| 재미 유형 | 0–100% 가로 막대 | 긍정·혼합으로 분류된 리뷰. 복수 분류 |

비추천 연관 차이 = 해당 주제 언급 리뷰 제외 추천률 − 전체 수집 추천률.
가중치 없는 수집 원자료 기준이며, 개선 효과나 인과관계를 뜻하지 않는다. 주제 간 중복으로 합산 불가.
플레이 구간은 서로 다른 작성자 집단으로 이탈률이나 시간에 따른 개인의 만족도 변화가 아니다.
최신순 수집은 무작위 추출이 아니므로 표본 수 기반 오차를 전체 유저 정확도 보장으로 제시하지 않는다.
작성 시 플레이 시간 0은 유효값으로 유지하고, 누락은 현재 누적 시간으로 대체하지 않는다.

## 적용 지침

- 제품 공통 지침: 밝은 작업 배경, 본문 14px, 보조 13px, 패널 16px 모서리, 파랑은 선택과 긍정 근거에 제한해 사용한다.
- [dashboard-design](https://github.com/mares29/dashboard-design-skill): 판단 중심 정보 순서와 단계적 상세 공개.
- [visualize-data](https://github.com/openai/plugins/blob/main/plugins/data-analytics/skills/visualize-data/SKILL.md): 차트 선택, 공통 축, 분모, 직접 라벨, 실제 화면 검증. 기존 제품 화면에 구현.
- [build-dashboard](https://github.com/openai/plugins/blob/main/plugins/data-analytics/skills/build-dashboard/SKILL.md): 요약→진단→근거 구조.
- Impeccable 4.3.1: 시각 계층, 반응형 배치, 키보드 포커스, 불필요한 화면 분기 제거를 점검한다. 개발 보조 도구이므로 실행 의존성에는 포함하지 않는다.
- [Steam API](https://partner.steamgames.com/doc/store/getreviews): 추천 여부, 작성 시 플레이 시간, 수집 정렬 정의.
- [MDA 원문](https://users.cs.northwestern.edu/~hunicke/MDA.pdf): 재미 분류의 개념적 근거. AI 분류의 정확도 검증을 대체하지 않음.

## 확인 결과

- 팰월드 원자료: 수집 2,188건, AI 분석 1,330건, 주제별 불만을 포함한 고유 리뷰 163건, 그중 추천 108건.
- 저장 불만 20건과 원문 조회 결과 20건 일치. 칭찬 0건은 빈 상태 표시.
- API 잘못된 페이지 번호 422, 결과 없는 게임 404 확인.
- 집계 단위 테스트 6개 통과: 0시간·시간 미상, 중복 주제, 추천과 감성 분리, 분모, 원문 필터, 부분 손상 파일, 빈 데이터.
- 브라우저에서 데스크톱 배치, 주제 선택, 원문 열기·닫기, 빈 필터, 구간 시각화 확인. 콘솔 오류 없음.
- 좁은 화면에서 기존 사이드바 고정 최소 폭 충돌을 수정하고 큰 차트는 글자를 줄이지 않고 가로 스크롤 제공.

기존 AI 분류 결과를 재분석하지 않았으므로 잘못된 주제 분류와 원인 추정은 남을 수 있다. 원문 연결과 AI 요약의 추정 표시로 확인할 수 있게 한다.
